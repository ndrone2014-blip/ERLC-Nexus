Set it up on your PC

About 15 minutes. Windows, with Linux/macOS scripts included.

  1. Install Python 3.12+ from python.org and tick “Add python.exe to PATH”.
  2. Download and extract ERLC Nexus, then double-click install.bat. It creates config.env.
  3. Create a Discord application and copy its Application ID, Client Secret and Bot Token into config.env. Add the redirect http://localhost:8420/auth/callback.
  4. Add your ERLC server key (in-game: Settings → ER:LC API) — or add it later on the website.
  5. Double-click start.bat and open http://localhost:8420. Sign in with Discord.
  6. Go online: double-click start-online.bat instead to get a free public https:// link your whole community can open.
